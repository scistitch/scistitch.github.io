Make development easier to repeat

Open-source tools created by SciStitch founder Ivan Ogasawara and developed with their communities.

Makim

Run common tasks the same way

Makim puts build, test, and data tasks in one YAML file. A new teammate can use the same documented commands as the rest of the team and run them in CI.

See Makim’s task examples

Sugar

Make container setups easier to repeat

Sugar gives Docker Compose setups named profiles. Each profile records which services, configuration files, and environment settings to use for development or testing.

See Sugar’s configuration examples

Build for a specialist workflow

Independent projects Ivan helps develop across health research, education, and scientific computing.

HiperHealth

Keep AI workflow steps reviewable

A Python library for clinical research workflows separates document extraction, data collection, and AI steps. Parquet sessions save a history that can be reopened for analysis.

Open-source library in development

Inspect the HiperHealth library

FreeCampus

Reuse exercises across courses and notebooks

FreeCampus Tools lets educators write a quiz once and reuse it on a course page, in Jupyter, or in Colab. Its authoring tools and course materials are public.

Learning app in development

See a reusable FreeCampus quiz

Arx ecosystem

Build a language around scientific data

Arx parses typed source, ASTx represents its syntax, and IRx compiles it through LLVM. Apache Arrow supplies the data containers. Related tools cover packaging, notebooks, and scientific computing.

Experimental compiler ecosystem

Explore Arx components and status

Earlier research collaborations

Contributions made through Open Science Labs before SciStitch.

Infodengue

Built visualizations and contributed to web and deployment workflows for Brazil’s mosquito-borne disease monitoring initiative, co-founded by Flávio Codeço Coelho and other researchers.

LiteRev

Provided technical leadership and worked on search, background processing, and benchmarking for literature review software. The University of Geneva founding team includes Erol Orel, Fatma Aziza Merzouki, and Olivia Keiser.

Open Science Labs tooling

Developed shared CI, bots, and web infrastructure, and contributed to PyMedX, a Python library for accessing PubMed.

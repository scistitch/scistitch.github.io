Make development easier to repeat

Makim

Give the team one set of commands

Makim puts build, test, and data tasks in one YAML file, so new teammates and CI can run the same documented commands.

See Makim’s task examples

Sugar

Save a container setup for each environment

Sugar stores the Docker Compose services and configuration for development or testing in named profiles. Teammates can run the same setup without piecing together command-line options.

See Sugar’s configuration examples

Software for research and education

HiperHealth

Keep AI workflow steps reviewable

HiperHealth separates document extraction, data collection, and AI processing so clinical researchers can review each step. It saves sessions in Parquet for later analysis.

Early development · Production targeted for early 2027

Inspect the HiperHealth library

FreeCampus

Reuse exercises across courses and notebooks

FreeCampus Tools lets educators write a quiz once and reuse it on a course page, in Jupyter, or in Colab.

Learning app in early development · Production targeted for early 2027

See a reusable FreeCampus quiz

Arx ecosystem

Build a language around scientific data

Arx explores how a custom language can work with scientific data. Its frontend parses the code, ASTx represents its structure, and IRx compiles it through LLVM. Apache Arrow provides the data containers.

Experimental · Production targeted for early 2027

Explore Arx components and status

Research software collaborations

These contributions predate SciStitch and were made through Open Science Labs.

Infodengue

Built visualizations and contributed to web and deployment workflows for Brazil’s mosquito-borne disease monitoring initiative, co-founded by Flávio Codeço Coelho and other researchers.

LiteRev

Provided technical leadership and worked on search, background processing, and benchmarking for literature review software. The University of Geneva founding team includes Erol Orel, Fatma Aziza Merzouki, and Olivia Keiser.

Open Science Labs

We worked on shared CI pipelines, bots, and websites for Open Science Labs. We also contributed to PyMedX, a Python library for accessing PubMed.
